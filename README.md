# 光电研学软件原型

这是一个纯静态前端原型，适合部署到 GitHub Pages。当前已经拆分为两个使用入口：

- `index.html`：入口选择页
- `frontend/`：家长 / 学生端，包含课程浏览、报名、日程、反馈、资源、社区、签到和证书
- `backend/`：学校管理端，包含课程发布、报名审核、日程管理、反馈查看、资源管理、社区管理、签到和证书
- `shared/app.css`：两个端共用的响应式视觉样式
